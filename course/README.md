# Course slides

Put chapter Markdown files and the shared `images/` folder here.

- Follow [PIPELINE.md](../PIPELINE.md): approve the outline, then the spine skill, then the content skill.
- Start from `sample-course.md` in this template to learn layouts, or replace it with a multi-file course (`00-introduction.md`, `01-….md`, …). The setup script does not copy the sample into new course repos.
- Stock intro images are in `images/`: `roi-logo-with-name.png`, `welcome.png`, `agenda.png`, `who-should-attend.png`, `prerequisites.png`, and `qa.png`. Reuse them; do not regenerate.
- The spine comes from `.agents/skills/course-spine-generator/SKILL.md`. Teaching slides come from `.agents/skills/course-generator/SKILL.md`. A lab slide’s body is `Lab link: TODO`.
